2 功能说明

功能当前实现
文字与参考图审核支持仅文字同步快速审核（POST /api/review/tasks?wait=1）或图文异步审核，返回规则判定结果、处置状态、前端提示文案及耗时。
规则配置每条规则合并为单一「规则说明」文本框（同时包含判定标准与排除边界），并为每条风险规则提供独立的「前端提示文案（block_message）」与拦截阈值配置；保存为新版本不覆盖历史记录。
模型配置渠道、模型 ID、图文能力、启停、超时、密钥状态和主备模型分配。
结果与记录展示精简冗余字段（移除内部英文标识、重复的生成/发布许可与冗余状态提示），直观展示判定结果、前端提示语、命中的中文规则名、逐项概率分值及每次模型请求响应。
三笙通用生图接入在三笙前端（sansyn-pc-v3）工作台「通用生图」点击「立即生成」时，先将用户输入的文字提示词送审；若命中规则，在提示词输入框下方红字展示审核后台配置的建议修改文案。

当前服务使用 Next.js、SQLite，默认审核判定模型为 LoopRouter 的 gpt-6-luna。

2.1 三笙通用生图接入约定

项目交互与结果约定
触发时机用户在工作台「图片生成 → 通用生图」输入提示词并点击「立即生成」时触发。
送审范围仅发送用户输入的文字提示词（通过 POST /api/review/tasks?wait=1 同步返回判定结果），保证最低延迟。
命中提示口径采用温和建议口吻：「该提示词可能涉及……，建议修改（可能影响生成结果）」，具体文案可在审核管理台「审核规则」页逐条配置。
多规则命中合并同时命中多条规则时自动合并去重（例如：「该提示词可能涉及版权角色 / IP、政治敏感内容，建议修改（可能影响生成结果）」），避免重复堆砌。
输入框交互命中时提示词输入框边框高亮为红色，并在输入框内下方展示提示文案；用户修改提示词内容后自动清除提示。

4 接口约定

4.1 模型服务接口

地址：POST https://api.looprouter.com/v1/decisions。请求头为 Content-Type: application/json 和 Authorization: Bearer 服务端密钥。

请求或响应字段内容
model实际请求的模型 ID，当前为 gpt-6-luna。
input 中的 developer平台审核指令，保留完整内容。
input 中的 user待审文字或图片；input_json 携带 unit_id、modality。
questions全部适用规则；每题包含 type、name、instructions（直接取自单框「规则说明」）。
answers供应商原始判断；正常是非题包含 type、name、probability，probability 范围 0 至 1。

第 1 节显示的是这一层实际模型请求与原始响应。审核服务再按生效阈值形成 ALLOW 或 BLOCK，并组装对应的 block_message。

4.2 本地业务接口

方法及路径数据
POST /api/review/tasks输入 prompt、images；传 ?wait=1 时同步等待判定完成并直接返回完整结果（含 action、block_message、block_messages），不传时返回 task_id、reused。
GET /api/review/tasks审核记录列表；筛选参数 action、status、limit。
GET /api/review/tasks/{id}执行状态、处置、前端提示文案、逐项判断、素材及模型调用明细。
GET /api/review/assets/{id}受控参考图。
GET、POST /api/review/policies当前及历史规则版本、单框规则说明、前端提示文案与阈值变更。
GET、POST /api/review/health模型配置状态、实际连接测试结果。
GET、POST /api/admin/decision-models判定模型及渠道配置。
PATCH /api/admin/decision-models/{id}模型配置变更。
POST /api/admin/decision-models/{id}/test指定模型的实际测试结果。
GET、PUT /api/admin/config审核主备模型等运行配置。
