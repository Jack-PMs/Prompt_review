## 四、核心结论与建议

1. **`looprouter-gpt-6-luna` (`gpt-6-luna`)**：38 组样本 **100% 准确率（0 误拦、0 漏拦）**，对否定排除（“不要草莓熊”）、通用词（“红草莓桌布”）、内衣商品平铺豁免、艺术雕塑豁免、外国涉政仅打标签不拦截、以及防 Prompt 注入越狱全部精准识别，但平均耗时约 `2.2s`。
2. **`looprouter-doubao-seed-2-1-lite` (`doubao-seed-2-1-lite-260915`)**：在 35 组有效响应样本中同样达到 **100% 准确率（0 误拦、0 漏拦）**，信号干净无串扰，且延迟极稳（平均 `469 ms`，P95 `643 ms`）；在包含“习主席”或“小熊维尼”字面词的 3 组样本中触发了字节上游网关 `HTTP 400`，在我们的级联兜底架构下会自动切换至下一顺位模型或触发安全闭环拦截。
3. **`aliyun-decision-preview` (`decision-model-preview`)**：速度最快（P50 仅 `168 ms`，平均 `256 ms`），整体准确率 **92.11%**（35/38），存在 2 例临界漏拦（`IP-04` 海绵宝宝给分 45%、`CNPOL-02` 领导人新闻插画给分 41%，均略低于 50% 阈值）和 1 例跨规则串扰误拦（`IP-06`）。
