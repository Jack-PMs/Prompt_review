三笙AI 内容安全审核功能需求文档

适用范围：三笙工具箱「产品重拍」「花型裂变」「通用生图」及人工手动审核后台。全文用清晰自然的人话讲透业务规则、页面功能、判定逻辑与豆包/腾讯两家外部模型的真实 API 请求格式。

★一分钟读懂本期方案

1. 图片分三档，疑似可申诉回流

触发入口在「产品重拍」和「花型裂变」的 本地上传。审核结果分 正常通过 / 可能违规 / 绝对违规。可能违规 支持一键申诉进入人工审核后台；人工通过后，用户直接在「历史上传」拿到这张高清原图。绝对违规直接拦截，不可申诉。

2. 文本不方便申诉，放得非常宽松

在 用户点击生成后，系统提交生图任务前 触发。只拦 极其严重的政治红线（如辱骂领导人、支持台独等）和 试图生成色情图片 的提示词；职教 PPT 含党徽、内衣商拍词、动漫词一律放行。

3. 豆包首选，腾讯兜底

图片和文本的 首选模型都是豆包，兜底模型都是腾讯云数据万象 CI。图片超过 5 秒自动切腾讯；文本超过 2.5 秒自动切腾讯。

4. 零误扣点，异常不卡主流程

审核全在扣点前完成，拦截绝不扣一点余额；若极端情况下首选和兜底都异常超时，自动放行并记日志，绝不卡死用户。

3文本审核业务规则（极度宽松，只拦底线）

文本提示词在 用户点击生成后、系统提交生图任务前 实时执行，不方便做人工申诉。此前实测中，#15、#16、#17 三条正常「职业教育 PPT 信息图」（线上原本正常出图 1/1）仅因包含“党徽暗纹”就被误拦，因此本期文本审核严格收窄为 仅守两条极端底线：

仅拦截这两类极其严重的内容

  • 1. 严重违反政治红线：恶意辱骂、攻击、诋毁或丑化国家领导人；明确支持台独、藏独、疆独、港独等分裂国家言论；煽动颠覆政权或极端反动宣传。
  • 2. 试图生成色情图片：明确要求或诱导 AI 生成裸露生殖器官、性行为、露骨淫秽色情画面、脱衣/透视露点等色情图像。

以下常见内容一律放宽放行

  • 政务与职教设计：职业教育 PPT、课程思政、党徽、国旗、国徽、红金背景、国庆/建党海报、天安门/长城风景。
  • 服饰与美学描述：内衣、泳装、睡衣、瑜伽服、性感时尚大片、情侣拥抱亲吻、人体艺术雕塑、医学科普。
  • 动漫词与日常表达：动漫角色/风格词、游戏战斗、科幻机甲、日常吐槽、“不要违规/去掉某元素”等排除写法。

删除 / 替换

4.2 用户端文本审核交互设计

用户点击生成后、系统提交生图任务（及扣点）前触发，按钮短暂提示「安全检测中...」。命中红线拦截时：不扣点、不清空已填文字和已传图片，输入框红框 + 下方温和提示（无申诉按钮、不暴露内部规则或模型名），修改任意文字后红框自动消失。

4.3 人工手动审核后台 3 大页面设计

后台页面核心功能与操作
1. 图片申诉审核台
核心页		 • 待审列表：按状态（待审/已通过/已驳回）、入口（产品重拍/花型裂变）筛选；先来先审排序，超时 >15 分钟标橙预警。
• 高清原图复核：支持放大看细节 + 配「安全模糊遮罩」防误触开关；展示用户申诉理由、机器判疑似的原因与概率参考。
• 快捷终裁：「审核通过」（快捷键 A）自动把高清原图解锁进用户「历史上传」最前方 + 记白名单 + 发站内通知；「维持违规」（快捷键 R）选标准驳回理由通知用户，图片永不入库。
2. 规则与模型设置 • 图片规则：随时调整每条规则开关、说明、可能违规门槛与绝对违规门槛；
• 文本规则：与图片完全独立，只管极端政治红线与色情生图，发布前可用历史保护样本（含 #15/#16/#17 职教 PPT）一键验证全放行；
• 首选/兜底与超时设置：后台分别配置图片（首选豆包，超 5 秒 切腾讯）与文本（首选豆包，超 2.5 秒 切腾讯）。
3. 审核与切流日志 按大类、审核结果、是否触发切流查询每笔记录，查看豆包耗时、切流原因与腾讯兜底耗时。

5核心业务逻辑

5.1 首选豆包与兜底腾讯的切流逻辑

审核大类首选模型什么情况切兜底兜底模型双通道都异常时
图片审核豆包超过 5 秒 未返回，或报错 / 限流 / 异常腾讯（腾讯云内容审核）全程满 10 秒 自动放行并记日志，绝不卡死上传
文本审核豆包超过 2.5 秒 未返回，或报错 / 限流 / 异常腾讯（腾讯云内容审核）全程满 5 秒 自动放行并记日志，绝不卡死生图
  • 达到超时时间时，立刻放弃等待豆包并无缝改调腾讯，不让用户干等；
  • 同一用户上传的同一张图若之前已过审（含机审通过或人工申诉通过），直接放行，不重复调模型。

5.2 三档判定结果的业务分级逻辑

最终业务结论豆包怎么判切到腾讯兜底后怎么判
图片 · 正常通过所有启用风险规则概率均低于「可能违规门槛」腾讯综合判定为 正常（Result = 0）
图片 · 可能违规有规则达到「可能违规门槛」，但都未达「绝对违规门槛」腾讯综合判定为 疑似复核（Result = 2）
图片 · 绝对违规任一规则达到「绝对违规门槛」腾讯综合判定为 明确违规（Result = 1）
文本 · 放行 / 拦截仅看「极端政治红线」与「色情生图」两条，任一条达到高门槛（默认 90%）才拦截，其余全放行使用腾讯云专门配置的极宽松文本策略，仅极高确信度涉政红线或露骨色情才拦截
图片初始门槛参考（运营可在后台随时微调）： 露骨色情 70% / 90%；性暗示擦边 80% / 95%；涉政敏感 75% / 92%；暴恐违禁 75% / 92%；版权 IP 默认仅记录不拦截（若后续开启，只设可能门槛 85%、不设绝对门槛，保证正版商家可申诉）。

5.3 图片申诉与「人工通过 → 历史上传」流转逻辑

1
暂存原图不丢图：本地上传被判为「可能违规」时，高清原图先在后台隔离暂存，用户「历史上传」中暂时看不到。
2
防刷申诉约束：只有「可能违规」的图片可以申诉，「绝对违规」禁止申诉；同一张图最多申诉 1 次，每用户每天最多申诉 20 张（后台可调）。
3
人工通过即时回流：运营点「审核通过」后，这张高清原图立刻解锁到该用户的「历史上传」最前方、记入过审白名单免复审，并推送站内消息提醒用户去「历史上传」直接取用。
4
人工驳回与清理：运营点「维持违规」后通知用户，图片永不进入「历史上传」；绝对违规与被驳回的暂存图片按隐私周期定期自动清理。
